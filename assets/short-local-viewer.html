KRX CSV 두 파일로 보기

KRX에서 같은 잔고 기준일의 KOSPI, KOSDAQ 전종목 CSV를 각각 내려받으세요. 수량은 주, 금액은 원을 선택하세요.





한 날짜의 파일만 선택하면 금액·비중 순위는 볼 수 있지만 과거 추이는 표시하지 않습니다. 파일 자체에 기준일과 시장 정보가 없어 입력한 값을 사용합니다.

이력 포함 JSON으로 보기


지원하는 JSON 형식

schemaVersion: 1, metric: net-short-outstanding-balance, unit: KRW, investorSplit: unavailable, status: verified, asOf: YYYY-MM-DD, observedAt: 관측 시각, coverage: {complete: true, count, markets: [KOSPI, KOSDAQ]}, rows: [{code, name, market, balanceKRW, marketCapKRW, ratioPct, history: [{date, balanceKRW}]}]. 금액은 원 단위 숫자 문자열, history는 같은 집계 기준의 실제 관측일입니다.
